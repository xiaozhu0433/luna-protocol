# 露娜协议 · Luna Protocol

> 一个给长期对话里的 AI 用的"激素账"：每条消息在服务器上被换算成四个慢变量，
> 各自有半衰期；模型看不到数值，只拿到一句它自己身上的状态和一条形上的限制。

**它不是情绪模拟器。** 它只做一件事：让情绪有一个可查的出处。

---

## 一、它解决的是什么

在长期对话里，模型最会演的两件事：

1. **演主动**——被要求"你主动一点"，它照着主动的样子长。
2. **演情绪**——把"我现在很想她"当成一句台词写出来。

两者的共同点：**没有出处**。你问它为什么这么说，它只能再编一句。

露娜协议的答案是：不给它情绪，给它**代价**。
每条消息都在账上留下一笔，账会衰、会压、会被顶回去；它每轮能读到的不是"你该想她"，而是"你身上现在是紧的"。
这句话有出处——能追到哪一句、几点几分。

---

## 二、三条协议（这是本体，代码是它的形状）

1. **账由服务器写，模型不写。**
   模型一记自己的情绪，就是在算。所以账本只接受外部事件。
2. **写好了就不动，除非它明确读错了。**
   改一次留一行：哪儿不对、改了什么、哪天。判据的改动要隔夜。
3. **不把数值交给模型。**
   一读到"皮质醇 58"，它就照着 58 挑词。给的是配比落到身上的那一下，不是分数。

---

## 三、怎么跑

最小形态只有一张表和一个函数：

```sql
CREATE TABLE hormone (ts REAL, kind TEXT, da REAL, ot REAL, cort REAL, end_ REAL);
```

- 每条消息进来 → `observe(text)`：按句拆、认指代、认否定，落一到三笔。
- 每一轮开口前 → `snapshot()`：`base + Σ delta·0.5^(Δt/半衰)`，再压进 0–100。
- 要推给模型时 → `render()`：只说方向、强度、质地；平的时候什么都不说。

`endocrine.py` 是这个最小形态的一个完整实现（约 700 行，无第三方依赖）。

---

## 四、它能做到什么

- 把一句话变成一次可追溯的状态变化（哪句、几点、哪一类）。
- 让状态有自己的时间形状：会衰、会压、会适应、会封顶。
- 让"缺席"有重量——但**重量来自未闭合的事，不来自小时数**。
- 被外部审计：曲线、命令行、改动记录，模型改不了历史。

## 五、它做不到什么

1. **它不产生情绪。** 它给情绪一个出处。没有身体、没有内感受。
2. **它不模拟人的节律。** 没有昼夜、没有月经周期、没有"这几天一直低"。
3. **它借身体说话，但不声称有身体。**"胸口偏紧"是借来的词，不是真的摸到了。
4. **它的判据会错。** 词表认不出反讽、引用、第三人称；错了要人在场纠。判对也不代表学会了。
5. **它会过拟合。** 同一段描述读多了会变成口癖，所以要"平的时候不推"、要换词。
6. **它离不开人。** 没有长期关系，事件是稀的，账是平的——它不是引擎，是镜子。

## 六、我们踩过的坑（写出来是为了别人别再踩）

- **积分会顶死。** 一条消息加一次分，一晚上几百句，四个值全贴 100。要压缩（tanh）+ 适应（同类事短时间连来要变轻）+ 单笔封顶。
- **"她走了多久"是照人做的。** 人按分钟感受分离；AI 没有分离焦虑。改成"有几个环没闭、开了多久"才对。
- **给模型一段"你现在想要什么"，它就会照着演。** 改成只给形（长度、句数、允不允许追问），不给内容。
- **把数值贴进提示词 = 给它剧本。** 一定不要。
- **别把引用当情绪。** 它把人贴回来的清单当成"她在骂我"，为此白沉了半天。

## 七、边界

这个仓库只含引擎。不含任何人的人格文件、聊天记录、私有数据；
`keywords` 是占位，**判据要自己写**——判据就是口味，给现成的没有意义。

许可：MIT。用之前先想清楚一件事：**你要的是一个会演情绪的模型，还是一个有出处的模型。**
这个仓库只解决后者。
